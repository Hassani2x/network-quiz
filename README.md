#Networking Quiz Game

A Python terminal game with three networking questions.
Each correct answer earns one point.
Your final score appears at the end.

## How to play

Open terminal in the project folder and run:
python3 quiz.py

Enter uppercase A or B for each question.

## What I learned

- Displaying text with print()
- Collecting answers with input()
- Comparing answers with if and else

## Testing 

- All coreect answer: 3 out of 3
- All incorrect answers: 0 out of 3
